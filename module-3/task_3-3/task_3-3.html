1. [ What is the difference between invoking and creating a function?]

    2. [When we create a function, what happens is that we declare the function, give it a name, list its parameters, and write the block of code it should perform. In this case the code inside the function does not run when it is created. It merely stores the instructions in memory. While invoking a function triggers or runs the stored function by using its name and passing values into the parameters. In this case the CPU jumps to the function's block, runs the code, and returns a result back to the program.]

  2. [Explain the syntax regarding semicolons and code blocks.]

    3. [Semicolons act like periods in a sentence, telling the ccode that a single instruction or statement has finished. Meanwhile code blocks group multiple statements together so they can be treated as a single unit (eks: function, loop, or if/else statement)]

  3. [What happens when we try to store values from a function when it doesn't return any?]

    4. [In when we try to store a function that does not have a return statement, the variable will store the value "undefined"]

  4. [How do we separate parameters from each other when creating a function?]

    5. [When creating a function in JavaScript, we separate parameters by using commas ","]

  5. [Explain how parameter names are related during the invocation and creation of a function.]

    6. [When we create a function, we can write placeholder names called formal parameters to show what data the function needs. And When invoke the function, we pass in the actual values, known as arguments. The computer automatically pairs them up—either by the order that the code was typed in them, but sometime it can sort by matching the names directly, that way the function can use the real data under its placeholder names.]

  6. [Explain why a parameter is undefined when a function call is missing a parameter.]

    7. [In JavaScript, a parameter becomes undefined when a function call is missing an argument because the language engine automatically assigns that unsupplied local variable with a placeholder value representing the absence of an assigned value, thus undefined]

  7. [Explain what happens when we use recursive functions.]

    8. [When we use a recursive function, the program executes a process where the function calls itself to solve a complex problem by breaking itself down into smaller sub-problems.]
